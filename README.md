# Portfolio - Matéis Cherpeau

Ce dépôt contient le code source de mon portfolio professionnel. 

## 🚀 Présentation
Mon portfolio est une vitrine interactive présentant mon parcours, mes compétences en Mesures Physiques et mes expériences dans le domaine du Volley-ball et de l'animation.

## 🛠️ Technologies utilisées
- **HTML5** & **CSS3** (Design responsive, Animations personnalisées)
- **JavaScript (ES6+)** (Gestion dynamique des contenus, Modales, Système multilingue)
- **GitHub Pages** (Hébergement)

## 📁 Structure du projet
- `/assets` : Images, icônes et documents (CV, rapports)
- `/css` : Feuilles de style organisées par composants
- `/js` : Logique du site et données des traductions (FR/EN)
- `index.html` : Page principale

## 🔒 Confidentialité
Ce site est protégé contre l'indexation par les moteurs de recherche via un fichier `robots.txt`. Merci de ne pas partager ce lien publiquement sans autorisation.
